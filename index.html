Pengaturan Tarif

Perubahan dipakai pada perhitungan baru, tersimpan lokal untuk offline, dan tersinkron otomatis ke Supabase saat perangkat online.

Pengaturan berasal dari versi lama atau sebagian nilai tidak valid dan telah dikembalikan ke default. Periksa kembali seluruh tarif, kemudian tekan Simpan Pengaturan.
Backup JSON tetap tersedia untuk arsip manual atau pemulihan darurat. Sinkronisasi utama berjalan otomatis melalui Supabase.

Sinkronisasi Supabase

Data tersinkron otomatis ke cloud dan bukti pembayaran tersimpan di Supabase Storage. LocalStorage tetap digunakan agar aplikasi berjalan offline.

Menyiapkan sinkronisasi
Aplikasi memakai akun email dan password. Data cloud dicek terlebih dahulu sebelum upload agar data lama tidak tertimpa.
